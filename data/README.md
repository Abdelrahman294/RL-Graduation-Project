# Dataset files

This folder contains the seven CSV recordings required by the temporal GNSS project (`cs.csv`, `ds1.csv`, `ds2.csv`, `ds3.csv`, `ds4.csv`, `ds7.csv`, and `ds8.csv`). They are copied from the `data_new` folder previously stored beside this repository. The project configuration reads them from this folder using a repository-relative path.

Keep these files together with the code when sharing the repository. Do not commit private recordings, credentials, or other sensitive data here.
